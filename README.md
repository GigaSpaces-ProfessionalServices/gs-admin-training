# gs-admin-training

This Git contains relevant labs for GigaSpaces Admin Training.  
For more information please see our [course syllabus](https://docs.google.com/spreadsheets/d/10Svq6s90eDw-Ger8TJogyVWLy0FcdfSF3EgtilCd2XY/edit#gid=0).


## Following are the list of labs:

| Lab | Topic | Features | Directories |
|-----|-------|----------|-------------|
| 01 | GigaSpaces setup and installation | Introduction, one-click install script | [lab01-gs_setup/01-introduction](lab01-gs_setup/01-introduction)<br>[lab01-gs_setup/02-one_click_deploy](lab01-gs_setup/02-one_click_deploy) |
| 02 | GigaSpaces Basic Grid Overview | Start the service grid, self-healing | [lab02-service_grid](lab02-service_grid) |
| 03 | Application Components | Deploy/test/undeploy a space via CLI, REST, Ops Manager, GS-UI | [lab03-application_components](lab03-application_components) |
| 04 | The Bill Buddy Application | Deploy the BillBuddy space, feeders, distributed executor and web app | [lab04-BillBuddy_training_example](lab04-BillBuddy_training_example) |
| 05 | GigaSpaces Ops Manager | Ops Manager UI demo | [lab05-ops_manager](lab05-ops_manager) |
| 06 | GigaSpaces Metrics | InfluxDB, Grafana dashboards (Docker) | [lab06-metrics](lab06-metrics) |
| 07 | GigaSpaces Manager | Multi-manager cluster (Vagrant), ZooKeeper client example | [lab07-gigaspaces_manager](lab07-gigaspaces_manager) |
| 08 | Hot Deploy Procedure | Update PU code with the custom REST upgrade plugin | [lab08-hot_deploy](lab08-hot_deploy) |
| 09 | GigaSpaces Command Line Interface | `gs.sh` CLI | [lab09-cli](lab09-cli) |

| 11 | Grid Security | Secured grid, password encryption, roles, secured space | [lab11-security](lab11-security) |
| 12 | MemoryXtend | BillBuddy with RocksDB blobstore, restore from disk | [lab12-memoryxtend](lab12-memoryxtend) |
| 13 | Kubernetes | minikube, Helm charts, operator, vertical scaling | [lab13-kubernetes](lab13-kubernetes) |
| 14 | Storage Optimization | Compare storage types with heap dumps (Eclipse MAT) | [lab14-storage_optimization](lab14-storage_optimization) |
| 15 | GigaSpaces ODSX | Setup, tiered storage, data engine | [lab15-odsx](lab15-odsx) |
